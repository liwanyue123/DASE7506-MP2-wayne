# Clean-room development boundary

This repository was created on 26 October 2026 by cloning only the official
course repository at commit `bb801f4` from
`https://github.com/xudongwu-0/DASE7506-MP2`.

The implementation in this repository may use only:

- the official guide, starter code, data and fixed candidate embeddings;
- general machine-learning and numerical-programming knowledge;
- code written specifically for this repository with disclosed AI assistance.

It must not copy or import another student's source code, trained weights,
predictions, experimental records, report text or hidden answer tables. Question
IDs are used only for alignment. Test references are reserved for a single
post-freeze evaluation and may not influence training or model selection.

The original official files remain identifiable through
`code/PACKAGE_MANIFEST.json`. New source, artifacts and reports are documented
separately.
